# Вимоги до продукту (Product Requirements & Architecture Blueprint)

## 1. Концепція продукту (Product Vision)
Кросплатформний мобільний додаток (iOS та Android) нового покоління для створення цифрового гардероба. 
**Головна обіцянка бренду**: *"Оцифруй свій гардероб без зусиль за лічені хвилини та завжди знай, що вдягнути."*

---

## 2. Базовий функціонал MVP (Phase 1)

### 2.1. Модуль введення даних (Smart Ingestion)
1. **Імпорт за URL-посиланням**:
   - Підтримка топ-магазинів: Zara, ASOS, Mango, H&M, Massimo Dutti, Answear, Nike тощо.
   - Метадані: витягування фото високої роздільності, назви, бренду, категорії, ціни, сезону.
2. **Фотографування та завантаження з галереї**:
   - Автоматичне видалення фону (Background Removal AI) локально на пристрої або через API.
   - Автоматичне центрування та підгонка розміру під єдиний шаблон.
3. **Ручне редагування та тегування**:
   - Категорія (Верхній одяг, топи/сорочки, брюки/спідниці, взуття, аксесуари).
   - Колір (з палітри або автоматичне визначення піпеткою AI).
   - Сезонність (Весна, Літо, Осінь, Зима, Всесезонний).
   - Бренд, розмір, ціна покупки, дата додавання.

### 2.2. Візуалізація та навігація (Digital Closet UI)
- Сітка речей із фільтрацією за категоріями, кольорами, сезонами та брендами.
- Повнотекстовий пошук (наприклад, "біла сорочка льон").
- Лічильник загальної кількості речей та сумарної вартості гардероба.

### 2.3. Конструктор образів (Outfit Builder)
- Drag-and-drop полотно (Canvas) або інтерактивний слот-генератор (Shuffle).
- Збереження готових аутфітів у колекції (Робота, Побачення, Подорож, Спорт).

---

## 3. Наступні фази (Roadmap Phase 2 & 3)

1. **Phase 2 (AI Stylist & Context)**:
   - Інтеграція з прогнозом погоди (OpenWeatherMap API).
   - Щоденні персоналізовані рекомендації під поточну погоду.
   - Календар носіння (Outfit Logger) для розрахунку Cost-Per-Wear.
2. **Phase 3 (Smart Packing & Resale)**:
   - Розумний збирач валізи в дорогу.
   - Експорт неношених речей на маркетплейси (OLX, Vinted, Shafa).

---

## 4. Рекомендований технологічний стек (Tech Stack)

* **Мобільний клієнт (Кросплатформний)**:
  - **Flutter** (Dart) або **React Native** (Expo / TypeScript) — забезпечують 100% паритет функцій між iOS та Android при єдиній кодовій базі. Flutter особливо рекомендований для високої продуктивності анімацій канвасу та плавного скролінгу великої кількості зображень.
* **Бекенд & База даних**:
  - **Supabase** (PostgreSQL + Auth + Storage) або **Firebase** — миттєвий старт, надійне хмарне сховище для фотографій одягу, вбудована автентифікація.
* **AI & Сервіси обробки зображень**:
  - Rembg / Cloudinary / Photoroom API або локальні ML-моделі (CoreML на iOS / ML Kit на Android) для видалення фону.
  - LLM Vision (Gemini 2.5 Flash / GPT-4o-mini) для парсингу речей та категоризації.
