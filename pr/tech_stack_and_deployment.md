# Технологічний стек, безкоштовний деплоймент та середовище розробки

## 1. Аналіз та порівняння технологічних рішень

У вашому поточному середовищі розробки (**Windows 11 / Node.js 26.3.0 / Git 2.54.0**):

| Критерій | Варіант 1: React Native (Expo + TypeScript) | Варіант 2: Flutter (Dart) | Варіант 3: FlutterFlow (No-Code/Low-Code) |
| :--- | :--- | :--- | :--- |
| **Швидкість старту на вашому ПК** | **Миттєво** (Node.js та Git уже встановлені) | Потрібно встановити Flutter SDK, Java JDK та Android SDK (~1-2 години) | Потребує платної підписки для експорту коду в GitHub |
| **Тестування на iPhone з Windows** | **100% підтримується без Mac**: через додаток **Expo Go** (сканування QR-коду камерою iPhone) | На Windows не можна запустити iOS-симулятор (тестування тільки на Android або через хмарний білд) | Тестування через веб або хмару |
| **Взаємодія з AI (Antigravity)** | Ідеальна: Antigravity напряму створює компоненти, запускає бандлер, встановлює пакети через npm | Ідеальна: повний контроль над структурою Dart-проєкту та віджетами | Складна: AI не має нативного доступу до візуального інтерфейсу |
| **Продуктивність анімацій та Canvas** | Дуже висока (React Native New Architecture + Skia) | Максимальна (нативний графічний движок Impeller) | Середня |
| **Вартість розробки та деплою** | **0$ (100% безкоштовно)** | **0$ (100% безкоштовно)** | $30–$70/місяць (платна підписка) |

### Рекомендація архітектора:
1. **Якщо ви хочете миттєво тестувати додаток на своєму iPhone та Android прямо зараз з комп'ютера Windows** без покупки Mac та без тривалого налаштування Java/Android Studio:
   👉 **React Native з Expo (TypeScript)** є найшвидшим та найзручнішим варіантом.
2. **Якщо ви обов'язково хочете чистий Flutter**:
   👉 Ми можемо встановити Flutter SDK на ваш Windows прямо зараз через командний рядок (`winget install Google.Flutter`), налаштувати Android оточення і використовувати GitHub Actions для хмарної збірки під iOS.

## 2. Повністю безкоштовний стек деплойменту та інфраструктури (100% Free Tier)

| Компонент | Сервіс | Безкоштовний ліміт (Free Tier) | Чому це найкраще |
| :--- | :--- | :--- | :--- |
| **База даних та Auth** | **Supabase** (PostgreSQL) | 500 MB БД, 50,000 активних юзерів на місяць, вбудована автентифікація (Google, Apple, Email) | Повна заміна Firebase без ризику несподіваних рахунків, open-source |
| **Хмарне сховище фото одягу** | **Supabase Storage** | 1 GB безкоштовно (~10,000 стиснених WebP фото одягу) | Вбудований CDN, захищені посилання |
| **Хмарна збірка під iOS та Android** | **GitHub Actions** + **EAS Build** | 2,000 безкоштовних хвилин щомісяця на GitHub Actions + 30 безкоштовних збірок на місяць на Expo EAS | Автоматична компіляція `.ipa` для iOS та `.aab` для Google Play у хмарі (Mac не потрібен!) |
| **Автоматизація релізів** | **Fastlane** | Безкоштовно (Open-Source) | Автоматична відправка білдів у TestFlight та Google Play Console |
| **Видалення фону з фото (AI)** | Нативні локальні бібліотеки на телефоні | 0$ (виконує процесор смартфона) | Нульові витрати на дорогі серверні API (Photoroom тощо) |

> [!NOTE] Офіційні збори маркетів
> Сервери, бази даних, зберігання фото та CI/CD збірки є на **100% безкоштовними**. 
> Єдині неминучі витрати — це офіційні акаунти розробника:
> - **Google Play Console**: $25 (одноразово, назавжди).
> - **Apple Developer Program**: $99 / рік (необхідно для публікації в App Store).

## 3. Як AI (Antigravity) взаємодіє з проєктом

Ви підключаєте мене безпосередньо до робочої директорії проєкту:
1. **Керування кодом через інструменти**: Я безпосередньо створюю та редагую всі компоненти інтерфейсу, логіку парсингу, базу даних та навігацію.
2. **Командний термінал**: Я можу запускати компіляцію, тести, встановлювати бібліотеки та запускати dev-сервери.
3. **CI/CD пайплайни**: Ми створюємо файли GitHub Actions (`.github/workflows/deploy.yml`), які при кожному оновленні коду автоматично перевіряють тести і збирають додаток для App Store та Google Play.
